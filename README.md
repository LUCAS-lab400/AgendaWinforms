# Agenda WinForms

Aplicação simples de agenda de contatos desenvolvida em **C# com Windows Forms**.  
Este projeto foi criado para fins de aprendizado e demonstração de conceitos básicos de programação em C#.

---

## ✨ Funcionalidades
- Adicionar novos contatos
- Editar contatos existentes
- Excluir contatos
- Listar todos os contatos em uma interface gráfica
